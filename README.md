# Northstar Support Deflection MVP - Practice

This repository is being used to practise GitHub collaboration for the Northstar Sprint.

## Project Goal

Build a simple Support Deflection MVP that can reduce repetitive customer support tickets.

The three possible support categories are:

1. Order Status
2. Returns and Refunds
3. Stock Availability

For this practice project, we will demonstrate:

- Order Status
- Stock Availability

## Team Collaboration Practice
